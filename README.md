# Sistem Manajemen Kas Mahasiswa

Aplikasi manajemen kas mahasiswa berbasis desktop yang dikembangkan menggunakan Visual FoxPro.

## Overview
Proyek ini dikembangkan sebagai bagian dari tugas mata kuliah Pemrograman Berorientasi Objek di semester 2. Aplikasi ini dirancang untuk mengelola transaksi kas mahasiswa melalui sistem berbasis desktop yang terintegrasi dengan basis data.

## Features
- Sistem login pengguna
- Manajemen data mahasiswa
- Manajemen transaksi pendapatan dan pengeluaran
- Sistem basis data berbasis desktop

## Technologies Used
- Visual FoxPro
- Basis Data DBF

## How to Run
1. Buka Visual FoxPro
2. Buka file proyek (.pjx)
3. Jalankan formulir utama atau menu dari Manajer Proyek
4. Pastikan semua file proyek dan file basis data tetap berada di direktori yang sama

## Purpose
Proyek ini dibuat untuk meningkatkan pemahaman tentang pengembangan aplikasi desktop, manajemen basis data, dan desain aplikasi berbasis formulir menggunakan Visual FoxPro.
